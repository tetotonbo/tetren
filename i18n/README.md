# 英語表記のしくみ

テト練の日本語⇄英語切り替えは、ここにある辞書と `engine.js` を
`install.py` でHTMLに埋め込んで作っている。HTMLを直接いじらず、
**必ずこのフォルダを直してから入れ直す**。

## ファイル

| ファイル | 中身 |
|---|---|
| `ui.json` | 画面のボタン・ラベル・ツールチップ（315語） |
| `js.json` | JSが組み立てる文（231語）。`{0}` が数字などの差し込み口 |
| `log.json` | 更新履歴の本文（307語） |
| `engine.js` | 切り替えの本体。DOMを歩いて差し替える |
| `install.py` | 上の4つをHTMLに埋め込む。何度でも実行できる |

辞書は**日本語の原文がそのままキー**。HTMLやJSの日本語を直したら、
辞書のキーも同じように直す（キーが合わないと英語にならない）。

## 入れ直しかた

```
python3 -I "/Users/take/クロード/テトリス/i18n/install.py"
```

`demo/tetren.html` と `demo/tetren_mobile.html` が書き換わる。
**本番（リポジトリ直下のHTML）は触らない** — 本番へはデモのファイルを
そのままコピーして出す流れなので、ここでは手を出さないようにしてある。

実行すると `辞書 849語 を入れました` のように語数が出る。

## 気をつけること

- **`<body>` の直後に入る**。本体スクリプトが初期化中に `T()` を呼ぶので、
  後ろに置くと `T is not defined` で初期化が止まり、ミノが動かなくなる
- 入れ直しは `<!-- i18n:start -->` 〜 `<!-- i18n:end -->` を丸ごと差し替える。
  この印の中を手で直しても次の実行で消える
- スマホ版だけの上書きは `install.py` の中の `I18N_EN2`（語の置き換え）と
  `I18N_SEL2`（セレクタ指定で innerHTML を入れ替え）に書く。
  細い列からはみ出す語を短くするのに使っている
- HTMLを直したあとは**ブラウザのコンソールを必ず見る**。
  エラーが出ていても画面は一見まともに出ることがある

## 直したあとの流れ

1. このフォルダを直す
2. `install.py` を実行（デモが書き換わる）
3. ブラウザでデモを開いて確認（コンソールのエラーも見る）
4. 版を上げて `CHANGELOG.md` と更新履歴の `vl-item` に追記
5. デモとしてコミット
6. 「反映して」と言われたらデモのHTMLを直下へコピーして本番公開
